# Academic Integrity in ActionAgent

ActionAgent is built to support learning and planning—not to complete assignments for students.

## Key principles

- Do not auto-submit assignments or take exams.
- Never generate full essays without user review.
- Provide sources, citations, and reasoning for every research summary.
- Encourage the student to edit drafts and confirm final submissions.
- Use explainable outputs so learners understand the result.

## How ActionAgent stays student-friendly

- It creates study schedules, outlines, and flashcards rather than finished papers.
- It flags recommendations as suggestions, not final answers.
- It keeps the user in the loop for Google Docs content creation and calendar scheduling.
- It avoids shortcutting academic work by breaking tasks into learning steps.
